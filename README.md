# VPN Scout
1. Создайте репозиторий на GitHub и загрузите туда содержимое этой папки.
2. Вкладка Actions -> Build APK -> после завершения скачайте артефакт VpnScout-apk.
3. Либо откройте папку в Android Studio: Build -> Build APK.
Для подключения нужно приложение "OpenVPN for Android" (F-Droid) или OpenVPN Connect.
